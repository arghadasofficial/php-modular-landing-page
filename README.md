## Features
*   **Component-Driven Frontend:** UI elements are isolated for easy reuse.
*   **Modular Layouts:** Headers, footers, and structural elements are managed via partials.
*   **Lead Management Dashboard:** Built-in secure admin panel (`admin-panel.php`) to easily view and manage customer contact form submissions.
*   **Lightweight & Fast:** Built with vanilla PHP, Bootstrap 5, and optimized asset management without the overhead of a heavy CMS.

## Project Structure
*   `/assets` - CSS, JavaScript, and image files.
*   `/components` - Reusable UI widgets and frontend blocks.
*   `/partials` - Global layout elements (e.g., header, footer).
*   `/utils/db.php` - Database connection and configuration.
*   `admin-panel.php` - Secure backend dashboard for viewing `form_queries`.
*   `index.php` - Main entry point for the frontend website.
